# src/engine/ 🔧 — ระบบ (ไม่ต้องแก้)
- `chain/` on-chain: connect (กระเป๋า/network), addresses (สมุด address), erc20 (token ใดก็ได้ + approveIfNeeded), cache, rpcMeter, txError
- `ui/` off-chain: app (วาดหน้า/รัน tx/หน้าแจ้งค่าที่ขาด), helpers (format ตัวเลข/address, ลิงก์ explorer)
- `settings.js` อ่าน settings/.env (ไม่มีค่าสำรองในโค้ด)
